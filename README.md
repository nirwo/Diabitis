# הרגלים — אפליקציית אייפון לפני ואחרי ניתוח מיני מעקף

אפליקציה בעברית (SwiftUI, iOS 17+) לבניית ההרגלים שהדיאטנית ממליצה עליהם.

## מה יש באפליקציה

| לשונית | מה עושים בה |
|---|---|
| **היום** | מצב שתייה (מותר / להמתין עד…), מעקב מים, 5 ארוחות, חלבון (טבעת התקדמות ורעיונות להשלמה לפי שלב התזונה), ויטמינים, הרגלים יומיים, רצף ימים בלי מוגזים, צעדים והליכות. כשיש ארוחה שמחכה לאישור מופיע באנר "יש ארוחה לאישור". כפתור ⚙️ למעלה פותח את ההגדרות (הגדרות אינן לשונית) |
| **ארוחה** | טיימר של 15 דק' לארוחה עיקרית (10 לביניים). כפתור "לקחתי ביס" ננעל ל-30 שניות של לעיסה, עם רטט כשאפשר לקחת ביס הבא וטיפים מתחלפים. בסוף הארוחה — תזכורת מתי מותר לחזור לשתות. כפתור **"צלם את המנה"** מצלם את המנה ומציג כרטיס חי: הרכיבים שזוהו, החלבון, ועד 3 טיפים לשיפור הארוחה |
| **תזונה** | טבעת חלבון יומית, ארוחות היום, וקטע "לאישור" (ארוחות שמחכות לאישור, שהזיהוי שלהן נכשל, או שעדיין ממתינות מימים קודמים). תפריט ה-+ : צילום, תמונה מהגלריה או הזנה ידנית. אחרי צילום נשאלים "איך הכנת?" (אפשר לדלג). בנוסף: היסטוריית אכילה, וספרייה של מקורות חלבון, מתכונים וכללים. מתכון בהצעת AI ("תציע לי מתכון") לפי החלבון שנשאר ושלב התזונה |
| **ויטמינים** | רשימת תוספים עם שעות, סימון יומי ותזכורות. ניתנת לעריכה לפי ההמלצה האישית |
| **פעילות** | צעדים מאפליקציית בריאות (HealthKit) וגרף שבועי, תכנון 3 הליכות של שעה בשבוע, טיימר הליכה ורישום ידני |

### הגדרות (כפתור ⚙️ במסך "היום")
תאריך ניתוח, שעות ארוחות, משך ארוחה, זמן לעיסה, הפרדת שתייה (30 דק'), יעדי מים וצעדים, ימי ושעת הליכה, ובנוסף:

- **יעד חלבון** — אוטומטי לפי גובה ומשקל, או ידני. החישוב האוטומטי: משקל אידיאלי = 25 × גובה² (במטרים); בסיס "משקל מתוקנן" מוסיף למשקל האידיאלי מקדם (0.25 או 0.4) מההפרש עד המשקל בפועל, או בסיס "משקל אידיאלי"; מכפילים בגרמים לק"ג (ברירת מחדל 1.2); מינימום יומי 90 גר' (ניתן לשינוי). הנוסחה מסומנת באפליקציה **לבדיקת הדיאטנית**.
- **שלב תזונה** — אוטומטי לפי תאריך הניתוח, או בחירה ידנית.
- **זיהוי ארוחות דרך המק** — כתובת הגשר והטוקן (ראו למטה).

### תזכורות (התראות)
- לכל ארוחה, ו-30 דק' לפניה: "זה הזמן לסיים לשתות"
- 30 דק' אחרי סוף ארוחה: "אפשר לחזור לשתות"
- ויטמינים בשעה שנקבעה לכל תוסף
- הליכה בימים ובשעה שנבחרו
- לגימות מים בין הארוחות (מדלג אוטומטית על חלונות הארוחה)

## היסטוריית אכילה

בלשונית "תזונה" ← "היסטוריה": ציר זמן של כל יום, עם בחירת יום מרצועת השבוע או קפיצה לתאריך.

- לכל יום: סך החלבון מול היעד, וכמה ארוחות נאכלו מתוך המתוכננות.
- בציר היום מופיעות הארוחות שתועדו, וגם ארוחות מתוכננות שדולגו ("דולגה") או שעוד בהמשך היום ("בהמשך").
- בימים קודמים מוצג היעד שהיה תקף באותו יום, ולא היעד הנוכחי. יום קודם שאין לו יעד שמור מציג את היעד הנוכחי, עם התווית "יעד נוכחי". בהפעלה הראשונה אחרי העדכון, ימים קודמים שיש בהם ארוחות ואין להם יעד שמור מקבלים פעם אחת את היעד הידני שהיה בתוקף לפני העדכון.
- בימים עברו אפשר לערוך ארוחה (לחיצה עליה) ולמחוק אותה (החלקה).

## זיהוי ארוחות דרך המק

זיהוי המנה מתבצע במק שלך, דרך "גשר" קטן (`bridge/server.py`, Python בלבד, בלי תלויות). הגשר מקבל את התמונה מהאייפון ומריץ `claude -p` על המק, עם גישת קריאה בלבד (כלי Read) לקובץ התמונה הזמני. מהתשובה האפליקציה מקבלת את הרכיבים, הגרמים, החלבון והטיפים. כל בקשה לגשר דורשת טוקן.

**דרישות**
- Claude Code מותקן ומחובר (login) במק.
- Tailscale על המק ועל האייפון, באותו חשבון.
- חומת האש של macOS צריכה לאפשר חיבורים נכנסים ל-Python של Homebrew שמריץ את הגשר. אחרי שדרוג של Python ייתכן שצריך לאשר אותו מחדש.

**התקנה**
1. במק: `bash bridge/install.sh`. הסקריפט מתקין LaunchAgent, מאזין רק לכתובת ה-Tailscale של המק, יוצר טוקן ומעתיק אותו ללוח.
2. באייפון: ⚙️ ← "זיהוי ארוחות דרך המק" — להזין את הכתובת שהסקריפט הדפיס ואת הטוקן (אפשר להדביק, בעזרת הלוח המשותף), ללחוץ "בדיקת חיבור". האפליקציה מקבלת כתובת Tailscale (וגם localhost, לפיתוח בלבד), והטוקן נשמר ב-Keychain.

**תחזוקה**
- לוג: `~/Library/Logs/bariatric-bridge.log`
- אחרי עדכון של `server.py` צריך להפעיל מחדש:
  `launchctl kickstart -k gui/$(id -u)/com.nirwo.bariatric-bridge`

> התמונות נשלחות ל-Claude דרך המנוי האישי שלך. ההגדרה הזו מיועדת לשימוש אישי.

## איך מתקינים על האייפון

צריך מק עם **Xcode 16** ומעלה.

1. לפתוח את `BariatricHabits.xcodeproj` ב-Xcode.
2. ללחוץ על הפרויקט ← Target **BariatricHabits** ← **Signing & Capabilities**, ולבחור **Team** (אפשר עם Apple ID רגיל). אם צריך — לשנות את ה-Bundle Identifier לשם ייחודי.
3. לחבר את האייפון בכבל (ולהפעיל Developer Mode באייפון), לבחור אותו למעלה וללחוץ ▶︎.
4. באייפון: הגדרות ← כללי ← VPN וניהול מכשירים ← לאשר את המפתח.

> אם יש בעיה עם קובץ הפרויקט, אפשר ליצור אותו מחדש עם XcodeGen:
> `brew install xcodegen && xcodegen`

## מבנה הקוד

```
BariatricHabits/
  BariatricHabitsApp.swift   נקודת כניסה, כיוון RTL ועברית
  Models.swift               מודלים וברירות מחדל (ארוחות, ויטמינים, הרגלים)
  AppStore.swift             מצב האפליקציה, שמירה ל-JSON, לוגיקת הפרדת שתייה
  MealTimer.swift            טיימר הארוחה (נשמר גם אם האפליקציה נסגרת)
  NotificationManager.swift  כל התזכורות
  HealthManager.swift        צעדים מ-HealthKit
  Nutrition/                 תזונה: מודלי אוכל, חישוב חלבון ויעד חלבון, שלבי תזונה,
                             היסטוריה, ספריית מזון, תור זיהוי ושמירת תמונות
  Bridge/                    לקוח הגשר (BridgeClient) ושמירת הטוקן ב-Keychain
  Resources/                 nutrition-library.json — ספריית מקורות חלבון ומתכונים
  Views/                     המסכים
    Nutrition/               מסכי התזונה: צילום, אישור ארוחה, היסטוריה, ספרייה, הגדרות יעד וגשר
BariatricHabitsTests/        בדיקות Swift
bridge/
  server.py                  הגשר ל-claude -p על המק
  install.sh                 התקנת LaunchAgent
  test_server.py             בדיקות Python
```

**הרצת בדיקות**
- Swift: `xcodebuild test -scheme BariatricHabits -destination 'platform=iOS Simulator,name=<סימולטור>'`. אם לא מותקן runtime של סימולטור, אפשר להריץ על המק עם היעד "My Mac (Designed for iPhone)" (`-destination 'id=<ה-id של My Mac מתוך xcodebuild -showdestinations>'`, עם `DEVELOPMENT_TEAM=<צוות>` בשורת הפקודה בלבד).
- Python: `python3 -m unittest discover -s bridge -p 'test_*.py' -v`

כל המידע נשמר מקומית במכשיר בלבד.
